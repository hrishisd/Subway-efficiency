# Report

- [`report.md`](report.md): the research report. **Generated** — edit [`report_template.md`](report_template.md), then run `python3 scripts/build_report.py`.
- [`figures/`](figures/): charts, generated by the same script.
- [`numbers.csv`](numbers.csv): every number computed for the report (ratios, shares, gaps), with its formula and the `obs_id`s it uses. `estimate = yes` when any input is an estimate.

Which row the report uses for each system, year and metric is fixed in [`../scripts/report_data.py`](../scripts/report_data.py).
